# -vad-
为解决传统离散情感分类难以细粒度刻画情绪状态的问题，本文围绕效价（Valence）、唤醒度（Arousal）和支配度（Dominance）三维情感模型，设计并实现了一个面向文本、图像、音频及视频场景的多模态融合情感分析系统。文本模态采用BERT表征与回归头实现VAD预测，图像模态基于FER2013映射构建视觉VAD回归模型，音频模态基于 Wav2Vec2构建音频VAD回归模型。在此基础上，提出视频输入下的模态自动切分流程，通过抽帧、抽音频与字幕提取分别完成三模态推理，并采用加权晚期融合得到最终情感维度结果。系统同时支持训练、评估、交互预测与批量导出，并在EmoBank、FER2013衍生数据、RAVDESS衍生数据和CMU-MOSEI数据上完成验证。
